# Portfolio de projets

Ce dépôt rassemble différents projets réalisés en **HTML**, **CSS**, **JavaScript** et **Python**. Ils ont été développés dans le cadre de l'apprentissage, de l'expérimentation ou de projets personnels.

## Contenu

Les projets couvrent différents domaines :

### Développement Web

- Jeux
- Outils et utilitaires
- Interfaces utilisateur
- Applications web

### Développement Python

- Scripts d'automatisation
- Exercices d'algorithmique
- Manipulation de fichiers
- Calcul scientifique
- Projets console
- Divers outils

## Installation

### Cloner le dépôt

```bash
git clone https://github.com/votre-utilisateur/votre-depot.git
```

### Accéder au dossier

```bash
cd votre-depot
```

## Lancer un projet Web

Ouvrir le dossier du projet puis lancer le fichier :

```
index.html
```

Ou utiliser Visual Studio Code avec l'aide d'un moteur de recherche pour afficher le projet.

## Lancer un projet Python

Accéder au dossier du projet puis exécuter :

```bash
python nom_du_fichier.py
```

ou selon votre installation :

```bash
python3 nom_du_fichier.py
```

Les éventuelles dépendances sont précisées dans le `README.md` du projet concerné.
