# Calculatrice Responsive

Application web de calculatrice réalisée en HTML, CSS et JavaScript. Elle permet d'effectuer les principales opérations mathématiques grâce à une interface simple et responsive.

## Fonctionnalités

- Addition
- Soustraction
- Multiplication
- Division
- Pourcentage
- Racine carrée
- Carré d'un nombre
- Inverse (1/x)
- Changement de signe (+/-)
- Suppression du dernier caractère
- Effacement complet de l'écran
- Gestion des erreurs de calcul

## Fonctionnement

L'utilisateur saisit une expression à l'aide des boutons de la calculatrice.

Les opérations sont affichées dans l'écran, puis évaluées lorsque le bouton `=` est utilisé.

Des fonctions supplémentaires permettent de :

- calculer l'inverse d'un nombre ;
- calculer le carré d'un nombre ;
- calculer la racine carrée ;
- inverser le signe d'une valeur ;
- supprimer le dernier caractère saisi ;
- réinitialiser complètement l'affichage.

En cas d'erreur de calcul, un message d'erreur est affiché avant que l'écran ne soit automatiquement vidé.
